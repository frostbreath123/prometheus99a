## 5. Environment and how to work

- **Linux builds and tests in WSL**: `~/p99b` is the working copy (the after-tree, with build directories). `~/p99` is the untouched baseline tree; keep it for before/after comparisons. Sync the Windows tree to WSL with:
  `wsl -e bash -lc 'rsync -a --exclude .git --exclude "build*" --exclude Prometheus99_Submission --exclude evidence --exclude "bench/results" /mnt/c/Users/Admin/Desktop/prometheus99-main/PROMETHEUSS/ ~/p99b/'`
- **Windows** builds in `C:\p99` (short path). Copy with `robocopy <repo> C:\p99 /E /XD .git build build-* Prometheus99_Submission evidence results`, then with `C:\msys64\ucrt64\bin;C:\msys64\usr\bin` on PATH: `mingw32-make -f Makefile.windows BUILD=build test-hmi-all ui-host`.
- **Run Linux suites one after another**, not in parallel (except `make -j8` inside one target).
- **Editing**: use the Edit and Write tools. Bash heredocs mangle backslashes (`\n`, `\0`, line-continuation `\`): for multi-line scripted edits write a Python file with the Write tool and run it. Keep LF line endings.
- **Before each batch of edits run `git status`**: the owner may stash or reset the tree. If work disappears, it is in `stash@{0}`: give the owner PowerShell restore commands (`git stash apply 'stash@{0}'`, quotes needed), never pop or drop yourself.
- **Size work**: the stripped size grows in 4,096-byte page steps. Check `readelf -lW build-musl/prometheus99 | grep LOAD` to see the slack before the next page. Every pointer in a static table costs a 24-byte relocation in the static PIE file (a table of string pointers once pushed a page; use fixed-size string arrays). Per-file cost: compile one file with `musl-gcc -Os -ffunction-sections -c` and run `size`.
