# Functionality preservation matrix

This matrix lists every major function of Prometheus99, the tests that cover it, the optimization changes that touched it, and the checks rerun after those changes. It was filled with the "before" status in phase 0 (2026-11-01) and is updated in the same step as each change (`docs/MASTER_PROMPT_FINAL.md`, section 4). The change identifiers (C1, C2, ...) refer to `docs/OPTIMIZATION_CHANGELOG.md`.

Status values: **verified** (the listed tests and checks ran and passed after the last change), **unverified** (not run after the last change, with the reason), **changed by request** (behaviour the owner asked to change, additive).

Last update: after phase 3 changes C14 to C17 (2026-11-02). C6 to C8 changed tests, the build and one line of the framebuffer backend; C9 changed how the comms thread sleeps; their checks are listed in the changelog.
