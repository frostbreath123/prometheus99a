Prometheus99 HMI

Screens of the real LVGL UI, rendered on a PC by the headless harness. Keys: left and right arrows, space plays.

1. Overview

Tag table with live values and quality. The setpoint panel is at the bottom. This build is the test build, so the banner says the role is not authenticated.

2. An alarm is raised

TANK_LEVEL passes its high limit. The header shows the alarm summary and the row is coloured.

3. Acknowledge and write

An operator acknowledges the alarm and sends a setpoint. Both are recorded in the audit file before they take effect.

4. PLC link lost

The link indicator changes, values show as unusable and no stale number is drawn as good.

5. Link recovered

The runtime reconnected by itself and the values are good again.

6. Viewer role

A viewer cannot acknowledge or write. The core refuses even if a button is forced.

7. Admin role

There is no login: the role is set when the program starts and the header shows it. Nothing authenticates it.

8. Alarm list

Most urgent first: priority, then unacknowledged, then newest. Each row has its own ACK.

9. Overview, last page

The tag table is paged.

10. Trends

Min and max per period for one tag. A break in the lines means no good data in that period.

11. No trended tags

A device without trended tags says so.

12. Settings: system

Read-only facts about the device: PLC, writes, configuration serial, storage, clock.

13. Settings: configuration, viewer

Only an engineer or an administrator can change settings.

14. Settings: number pad

An engineer edits an alarm limit with the number pad.

15. Settings: apply

Edits are shown as 'old -> new'. APPLY needs two presses. The rules are checked first.

16. Settings: result

The request goes to a root helper that re-checks it, signs the new configuration and restarts the service. The last answer is shown here.

17. Write sent, PLC silent

The write was recorded first and sent once. The PLC does not answer, so it is shown as SENT, not as done.

18. Write not confirmed

After the timeout the outcome is UNKNOWN or EXPIRED. The program never reports a confirmation it did not see.

19. Write refused by the PLC

A Modbus exception reply is shown as REJECTED.

20. Write applied, reply lost

The PLC changed the value but the reply never came: UNKNOWN (sent, no confirmation), sent exactly once.

21. Large numbers, long name, out of range

The largest 32-bit value, a long float, a negative number, the longest tag name and a value outside its range (UNCERTAIN RANGE).

22. After 40 rounds of screen changes

With static data the table is pixel-identical to the first visit.

Renderings from a PC with a fake PLC. Not shown on a real display, not measured on a Raspberry Pi.
